Upload orders or sales history

The first time, drop in the routing template (Routes - Delivery Days.xlsx, with the Vehicles tab) and postcode_cache.csv together with today’s orders. After that the addresses, vans and map locations are remembered, so each day you only drop in the order list. You can also drop in a stock movement export (Move Date, Move Type, Ref4): each delivery day in it is routed from the shops that were actually delivered that day.

Collections (door sales, not routed)

          Every plan uses today’s drops that have an address, the same vans, payloads, delivery times and working day. The cheapest plan that breaks no limit is picked automatically; you can switch to any other. The fixed template is shown only so you can see the saving.

          Template runs that pass near a place

          Uses the runs in the routing template (route number, name and drop order), with the shops and loads from the sales file and your vans matched to each run. A run counts if any drop, or the straight line between two drops, comes within the miles below.

          Vans

          Untick a van that’s off the road today. Fuel economy is a starting estimate (set below): put in each vehicle’s real mpg from the fuel card data for accurate fuel and CO₂.

          Planning rules

          Miles are straight-line distances × the road factor, so they’re estimates; “Draw on real roads” on a route measures the real road distance when the routing service can be reached. Loads come from Size × Pack × quantity; lines whose size can’t be read count as zero weight. Changing a setting re-optimises.
